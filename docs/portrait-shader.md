# Portrait route

`/drawloom/portrait-shader/` now opens the shared [Studio photo workspace](photo-workspace.md). Its default pipeline fits forms and planes before selecting facial structure and generating native text.

The older `PortraitShader` component and `src/lib/portrait/` prototype remain as an unapproved baseline. Their fixed construction recipe is not used by the current routes. Do not use their old tests or images as evidence that the general filter matches AAHub references.
